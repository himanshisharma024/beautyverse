# 🌸 BeautyVerse

AI-Powered Full Stack Skincare Web Application

BeautyVerse helps users discover skincare products based on
their skin type, concerns, and ingredients while providing
personalized recommendations.

## ✨ Features

- 🔐 User Authentication
- 🛒 Shopping Cart
- ❤️ Wishlist
- 🔍 Product Search & Filters
- 🤖 AI Skin Analysis Quiz
- 📦 Product Details
- 💳 Checkout
- 📱 Responsive Design

## 🛠 Tech Stack

Frontend
- React.js
- Tailwind CSS
- React Router

Backend
- Node.js
- Express.js
- MongoDB
